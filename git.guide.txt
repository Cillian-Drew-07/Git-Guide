Git Guide (Cillian Drew)
Command one: git init
It initialises local repo on PC
 
Command two: git add
It moves files from the pc to the staging area in prep for a commit

Comand three: git commit
Git commit moves files from the staging area to the repo

Command four: git status
Shows status of the branch



Command five: git log
Shows all your commits

Command six: git remote
Links the git hub and PC repos

Command seven: git branch 
Makes a branch

Command eight: git switch
Switches branches
